# 重复检测漏斗 · 标注基准集

> 一份带人工标注的成对样例，用来量「多报一级的漏斗，值不值」。

## 这套数据是什么

- `tables/科室一表.csv`、`tables/科室二表.csv`：两张脱敏的科室专项上报表，各 11 行。
  数据只含**指标级监管数据**（指标编号、分子分母、填报值、计量单位、业务主键），
  **无患者可识别明细**；机构代码、科室代码为样例值。
- `labels.json`：11 条**成对标注**。每条标注指出「表 A 第几行」与「表 B 第几行」
  是不是同一件事，以及判定依据。

标注用「来源表 + 行号」而不是行键：行键是算出来的 sha256 摘要，人读不懂、
改一行数据就得重算。装载时再解析成行键 —— 对齐仍然严格按行键走，但标注文件
是人能读能改的。定位不到行会直接报错（不静默跳过），否则标注文件里一个错字
会悄悄把召回率抬高。

## 三种标注分别是什么意思

| 标注 | 含义 | 漏斗该不该报 | 基准集里的条数 |
|---|---|---|---|
| `duplicate_record` | 同一件事被填了两遍 | **应该报**（正例） | 7 |
| `same_indicator` | 同一个指标，但不是同一件事（不同院区各报各的、业务主键不同代表两条记录、同键异值属订正） | 不该报（报了算误报） | 3 |
| `not_duplicate` | 明确不是同一件事（两个不同指标，名称相近） | 不该报（报了算误报） | 1 |

## 指标口径

- **召回率** = 命中真重复标注的候选对数 ÷ 基准集里真重复标注的对数（分母 = 7）。
  漏斗没报出来的真重复就是漏。
- **精确率** = 命中真重复标注的候选对数 ÷ 该级累计候选对数。
  **候选里没有标注的对一律算误报**（没标注不等于对，宁可严）。
- 每一级都是**累计口径**（跑到这一级为止一共报了多少）；「本级新增」单独一列 ——
  两个数一起看才知道这一级加进来多少、值不值。

## 怎么跑

```bash
# 产出逐级对比表（CSV）
cargo run -- bench --bench-dir samples/bench --out /tmp/dupe-bench.csv

# 产出机器读的 JSON（含结论、漏掉的真重复、边际增益）
cargo run -- bench --bench-dir samples/bench --out /tmp/dupe-bench.json
```

同一份输入跑两次，两个文件逐字相同（对比表里没有任何时间戳或随机数）。

## 这套数据刻意埋了什么

| 埋点 | 用意 |
|---|---|
| 机构代码 ORG-001 / ORG-002 两院区共用科室代码 0301 | 量「跨机构同科室代码」会不会被误判成重复（漏斗的业务主键不含机构代码） |
| 指标名称少一个字（「检查记录符合率」/「检记录符合率」） | 量字符级编辑距离这一级的增量 |
| 指标名称别名（「CT、MRI」/「CT/MRI」、「出院病历2日归档率」/「出院患者病历2日归档率」） | 量归一化这一级的增量 |
| 全角「％」与半角「%」 | 量单位别名归一后取值一致的情形 |
| 同一指标编号 + 同一业务主键 + 同一取值，但名称写成「计算机断层与磁共振检查记录符合率」 | **四级判据都认不出的真重复** —— 这一对是留给语义归并（模型级）的，也是判断「要不要留模型这一级」的依据 |
| 手术记录 vs 出院记录（名称相近、取值相同、不同指标） | 约束语义级不要越界 |

## 扩展这份基准集

1. 在 `tables/` 里加表（文件名主干 = 标注里写的「来源表」名）；
2. 在 `labels.json` 里加标注 —— 三种取值之一，`basis` 必填（写清为什么这么判）；
3. 跑 `cargo run -- bench --bench-dir samples/bench --out /tmp/dupe-bench.csv` 看新数字。

**行号会随表变动**：改表里的行要同步改标注里的行号，否则装载时报
`BENCH_SET_INVALID` 并点名是哪一条标注对不上 —— 这是故意的（错字会悄悄抬高召回率）。
